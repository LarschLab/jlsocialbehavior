# Remaining Work Index

Purpose: route agents to unresolved actionable work by workflow profile.

Use a workflow-specific tracker when meaningful work stops with known breakage, follow-up work, missing validation, or a blocked rerun.

## Trackers

- Social behavior analysis: `.agents/references/remaining-work-social-behavior-analysis.md`
- Notebook figure workflows: `.agents/references/remaining-work-notebook-figure-workflows.md`
- Video preprocessing and GUI: `.agents/references/remaining-work-video-preprocessing-gui.md`

When a tracked item is resolved, mark it resolved here or in the workflow tracker and log the completed fix in the matching recent-changes file.
